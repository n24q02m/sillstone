# sillstone-digest

> **Archived:** sillstone is no longer maintained. Published packages stay available on their registries but receive no further fixes, including security fixes.

Pure-Rust cryptographic and non-cryptographic hash algorithms (SHA-256, SHA-512, SHA-1, Murmur3, CRC32c, xxHash64).
Part of the Sillstone multimedia, hashing, and array computing suite.
